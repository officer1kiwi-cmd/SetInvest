หลักการคำนวณของ SET ALPHA QUANT

1. ตัวกรองราคา (Price Filter): คัดเลือกเฉพาะหลักทรัพย์ในตลาดหลักทรัพย์แห่งประเทศไทย (SET) ที่มีราคาซื้อขายปัจจุบันต่ำกว่า 7.00 บาท

2. การวัดความเติบโตต่อเนื่อง (Consistency Streak): เมื่อผู้ใช้ระบุจำนวน N ไตรมาส ระบบจะตรวจสอบย้อนหลังทีละไตรมาสเทียบกับช่วงเดียวกันของปีก่อน (YoY) ว่าทั้ง ยอดขาย, กำไรสุทธิ และ เงินปันผลต่อหุ้น มีการขยายตัวกี่ไตรมาสจากทั้งหมด N ไตรมาส

3. อัตราเติบโตทบต้น (Annualized CAGR): คำนวณอัตราการเติบโตเฉลี่ยต่อปีจากจุดเริ่มต้นของช่วงเวลา N ไตรมาสจนถึงไตรมาสล่าสุด เพื่อป้องกันความผันผวนระยะสั้น

4. การเชื่อมต่อ TradingView: ปุ่มดูกราฟจะนำทางไปยังสัญลักษณ์ SET:TICKER บน TradingView โดยตรงเพื่อวิเคราะห์แนวรับ-แนวต้านทางเทคนิค
